# Підключення Monobank Acquiring для Kadr Pro

Це **не код** — кроки в кабінеті monoбізнес. Паралельно можна розробляти на тестовому токені.

## 1. Інтернет-еквайринг

1. Увійдіть у [web.monobank.ua](https://web.monobank.ua/) / monoбізнес.
2. Підключіть **інтернет-еквайринг** для ФОП.
3. У заявці опишіть товар/послугу як:  
   **«Доступ до програмного забезпечення / онлайн-сервісу Kadr (редактор сторіс)»**.
4. КВЭД 62.01 / 58.29 / 63.11 підходять для цього опису.
5. На сайті мають бути оферта (`/legal/terms`), політика (`/legal/privacy`) і реквізити ФОП у футері (змінні `NEXT_PUBLIC_FOP_*`).

## 2. Токени

- **Тест:** токен з [api.monobank.ua](https://api.monobank.ua/) — працює без бойового терміналу; картки за алгоритмом Луна, гроші не списуються.
- **Бойовий:** після схвалення еквайрингу скопіюйте API-токен терміналу в кабінеті.

У `.env`:

```bash
MONO_TOKEN="..."
AUTH_URL="https://your-domain.com"   # для redirect/webhook URL
```

## 3. Webhook

URL: `https://your-domain.com/api/mono/webhook`  
Підпис `X-Sign` перевіряється ECDSA ключем з `/api/merchant/pubkey`.

Для локальної розробки потрібен публічний тунель (ngrok / cloudflared), інакше webhook не дійде — статусу вистачить сторінка `/pro/return` через `invoice/status`.

## 4. Регулярні списання (пізніше)

У кабінеті: термінал → Інтеграції → **Оплата по підписці** → заявка.  
У v1 Kadr Pro використовує **разовий invoice** на місяць/рік з `expiresAt` у БД.
